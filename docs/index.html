Explicação Didática

O que realmente significa ser 100% Offline?

A maioria dos serviços de transcrição envia o que você fala para servidores nos Estados Unidos ou Europa. Com o Transcritor Local, isso nunca acontece.

Como a maioria faz

Serviços Comuns na Nuvem

  • ✕ Seu áudio confidencial é enviado pela internet para servidores desconhecidos.
  • ✕ Suas conversas podem ser armazenadas, lidas por terceiros ou usadas para treinar novos modelos.
  • ✕ Se sua internet cair ou estiver lenta, a transcrição para de funcionar.
  • ✕ Cobrança por minuto gravado ou mensalidades caras após limite curto.
Com o Transcritor Local

100% Local no seu Computador

  • ✓ Zero saída de dados: O áudio nunca sai do seu disco rígido ou memória RAM.
  • ✓ Sem servidores externos: A Inteligência Artificial roda na sua máquina como uma calculadora local.
  • ✓ Funciona no modo avião: Transcreva em voos, locais remotos ou redes fechadas sem internet.
  • ✓ Ilimitado e grátis: Transcreva 1 minuto ou 100 horas sem pagar nada por isso.

Guia Rápido: Como rodar a partir do Git

# 1. Clone o repositório pelo Git

git clone https://github.com/Emersonjsc/transcritor-local.git

cd transcritor-local


# 2. Crie e ative o ambiente virtual Python

python3 -m venv .venv

source .venv/bin/activate # No Windows use: .venv\Scripts\activate


# 3. Instale os pacotes necessários

pip install -r requirements.txt


# 4. Inicie o Transcritor

python main.py

Recursos Técnicos

Feito com tecnologia de ponta

Arquitetura focada em baixo consumo de memória e máxima velocidade.

⚡

faster-whisper (CTranslate2)

Utiliza a biblioteca mais eficiente de inferência Whisper do mundo. Até 4x mais veloz que a biblioteca oficial e consome a metade da memória RAM.

🛡️

Zero Telemetria

Nenhum dado analítico, nenhum relatório de uso e nenhuma requisição de rastreamento é enviada para fora do seu sistema.

🎬

Áudio e Vídeo Integrados

O app extrai o áudio automaticamente de arquivos de vídeo pesados (como MP4 ou MKV) e transcreve sem que você precise converter antes.

📝

Salvamento Automático em .TXT

O texto transcrito é imediatamente gravado em disco no diretório de saída com o nome original do arquivo. Sem risco de perder o trabalho.

⚙️

Quantização INT8

Permite que modelos de altíssima precisão rodem de forma surpreendentemente ágil em processadores domésticos sem superaquecer a máquina.

🎮

Aceleração por GPU NVIDIA

Se o seu computador tiver uma placa NVIDIA compatível com CUDA, o app aproveita toda a potência da placa gráfica para transcrever quase instantaneamente.

Dúvidas Frequentes

Perguntas Comuns

O programa precisa de internet em algum momento?

Apenas uma única vez quando você escolhe um modelo novo para que ele seja baixado para a sua máquina (ficando na pasta models/). A partir daí, você pode desconectar a internet permanentemente se desejar.

Alguém pode escutar o que estou transcrevendo?

Absolutamente ninguém. O processamento é todo local. Não existe nenhum servidor intermediário, conta de usuário ou transmissão externa de dados.

É realmente grátis?

Sim. O Transcritor Local é um software livre e de código aberto. Não possui versões pagas, assinaturas, anúncios ou limitações artificiais de minutos.
